# 🐄 ฟาร์มโคนม — คู่มือติดตั้ง

## วิธี Deploy ขึ้นเน็ต (ฟรี) ใน 5 นาที

### ขั้นตอนที่ 1 — ติดตั้ง Node.js
ดาวน์โหลดได้ที่ https://nodejs.org (เลือก LTS)

---

### ขั้นตอนที่ 2 — เปิด Terminal แล้วรันคำสั่งนี้

```bash
# เข้าโฟลเดอร์โปรเจกต์
cd farm-app

# ติดตั้ง dependencies
npm install

# ทดสอบบนเครื่องก่อน
npm run dev
# เปิด http://localhost:5173 บน browser

# Build เป็นไฟล์สำหรับ deploy
npm run build
```

---

### ขั้นตอนที่ 3 — Deploy ขึ้น Netlify

**วิธีที่ 1: ลาก-วาง (ง่ายสุด)**
1. ไปที่ https://netlify.com → Sign up ฟรี
2. ไปหน้า "Sites"
3. ลากโฟลเดอร์ `dist` ไปวางในหน้าเว็บ
4. ได้ลิงก์เว็บทันที! เช่น `https://farm-abc123.netlify.app`

**วิธีที่ 2: GitHub (แนะนำถ้าต้องการอัปเดตง่าย)**
1. สร้าง repo บน GitHub แล้วอัปโหลดโปรเจกต์
2. ไป Netlify → "Add new site" → "Import from Git"
3. เลือก repo → Deploy อัตโนมัติ

---

### ขั้นตอนที่ 4 — ติดตั้งบนมือถือ

**Android (Chrome):**
1. เปิดลิงก์เว็บใน Chrome
2. กดเมนู ⋮ มุมขวาบน
3. กด "เพิ่มในหน้าจอหลัก"
4. ✅ แอปพร้อมใช้งาน!

**iPhone (Safari):**
1. เปิดลิงก์ใน Safari (ต้องเป็น Safari เท่านั้น)
2. กดไอคอน แชร์ 📤 ด้านล่าง
3. กด "เพิ่มไปยังหน้าจอโฮม"
4. ✅ แอปพร้อมใช้งาน!

## รหัสผ่านระบบ

| บัญชี | รหัสผ่าน | สิทธิ์ |
|-------|---------|-------|
| owner | 1234 | เจ้าของ — เห็นทุกอย่างรวมการเงิน |
| staff | 0000 | พนักงาน — บันทึกนม, แจ้งวัวป่วย |

---

## แก้ไขรหัสผ่าน

เปิดไฟล์ `src/App.jsx` หาบรรทัด:
```js
const ACCOUNTS = {
  owner: { password: "1234", ... },
  staff: { password: "0000", ... },
}
```
เปลี่ยนตัวเลขได้เลย แล้ว build ใหม่
